Política de Privacidade – CelebrePlus

Última atualização: ___/___/_____

Agradecemos por utilizar o CelebrePlus (“Aplicativo”, “nós”, “nosso”). Esta Política de Privacidade descreve como coletamos, usamos e protegemos suas informações ao utilizar nossos serviços.

1. Informações que Coletamos

1.1 Informações de Cadastro

  • Nome
  • E-mail
  • Senha (criptografada)

1.2 Informações do Evento (Anfitrião)

  • Nome e data do evento
  • Lista de presentes
  • Mensagens de convidados
  • Dados para geração de links de acesso

1.3 Informações de Interação (Convidados)

  • Presentes selecionados
  • Mensagens ao anfitrião
  • Confirmação de seleção de presente

1.4 Informações de Pagamento via PIX

O CelebrePlus não processa pagamentos. O convidado realiza o pagamento fora do app. O aplicativo apenas exibe o número PIX do anfitrião.

1.5 Dados Técnicos

Coletamos dados técnicos necessários para funcionamento, como dispositivo e sistema operacional.

2. Como Usamos as Informações

  • Gerenciar contas
  • Gerenciar eventos e listas
  • Permitir interação entre usuários
  • Melhorar o app

3. Compartilhamento de Informações

Os dados não são vendidos. O compartilhamento ocorre apenas quando necessário para funcionamento ou exigido por lei.

4. Segurança

Adotamos medidas de segurança para proteger os dados de acesso não autorizado.

5. Pagamentos

O pagamento via PIX ocorre externamente. O app não coleta dados financeiros.

6. Direitos do Usuário

  • Excluir conta e dados
  • Solicitar acesso às informações
  • Corrigir dados

7. Retenção de Dados

Mantemos os dados enquanto necessários ou enquanto a conta estiver ativa.

8. Serviços de Terceiros

Podemos utilizar serviços de hospedagem ou análise que possuem políticas próprias.

9. Alterações

Esta Política pode ser atualizada periodicamente.
